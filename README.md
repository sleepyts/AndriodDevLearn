# 学习安卓开发过程中写的一个Demo

通过调用网易云api实现一个简单的音乐播放器,仍在完善中...

已实现功能

- [x] 歌单获取
- [x] 歌单歌曲获取
- [x] 音乐播放，暂停，上下切换
- [x] 播放模式切换
- [x] 状态栏播放器
- [ ] 登陆
- [ ] 歌词
- [ ] 播放列表
- [ ] 音乐一系列操作
